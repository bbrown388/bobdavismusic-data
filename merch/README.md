# Merch artwork

`2-dolla-bill_burnt_transparent.png` is the burnt bill from the single cover, isolated with
real per-pixel alpha (regenerated from the cover pipeline rather than matted off the finished
artwork, so the charred edge and embers keep clean transparency).

Hosted here so it has a stable public URL for Printful and other print services. Same reason
the follower data lives in this repo: the website repo requires a pull request for main.

## Print sizing, and the rule that matters

31 CFR 411 requires printed illustrations of US currency to be **under 75%** or **over 150%**
of real size. A note is 156 mm long, so the forbidden band is roughly **117 mm to 234 mm**.

- Over 234 mm wide: fine. Full chest or back prints land here.
- Under 117 mm wide: fine. Left-chest and pocket prints land here.
- Between: do not print.
